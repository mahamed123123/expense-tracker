## What will (likely) be the title of your project?

Expense Tracker

## In just a sentence or two, summarize your project. (E.g., "A website that lets you buy and sell stocks.")

A Python program that helps users keep track of their income and expenses. It will show how much money they have left and where they are spending it.

## In a paragraph or more, detail your project. What will your software do? What features will it have? How will it be executed?

My project will be an expense tracker made in Python. When the user runs the program, a menu will let them add income, add an expense, view their transactions, or check their balance. For each expense, the user can enter an amount, a category, and a short description. The program will calculate total income, total spending, and the remaining balance. I plan to save the transactions in a CSV file so the information is still there the next time the program runs. The program will run in the terminal, and users will choose options by typing numbers into the menu. I also want to make sure the program handles invalid inputs without crashing.
